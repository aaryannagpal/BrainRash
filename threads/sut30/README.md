# sut30

A while back I found [`sutskever-30-implementations`](https://github.com/pageman/sutskever-30-implementations) on GitHub, 30 foundational papers, each one broken down into a clean, un-abstracted implementation. It stuck with me enough that I decided to work through the same list myself: implementing each paper and writing up what I actually learn along the way, leaning on the original repo for reference rather than copying from it.

More on why, here: [sut30-000](https://brainrash.substack.com/p/sut30-000).
