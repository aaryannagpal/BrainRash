# poker

Building a Texas Hold'em poker AI from scratch: both a real research-grade system and a public record of getting there. It starts from the game theory: regret matching, Nash equilibrium, CFR, working up from toy games before touching anything resembling real poker.

The core idea running through it: start from a GTO baseline, then shift toward exploiting specific opponents as data on them builds up.
